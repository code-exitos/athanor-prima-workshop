# Constraints

## Budget

- Small. The board approved a one-time amount for building the first version and a very small yearly amount for hosting.
- No monthly fee for software licenses.

## Infrastructure

- No server at launch. The board does not want to run, secure, or pay for one.
- The app must be able to be hosted as plain static files.
- There is no IT staff in the community.

## Devices

- Residents use many kinds of phones: recent iPhones, mid-range Android, and a few older ones.
- The guards share two phones. One is old.
- Nobody wants to install an app from a store. A web page is acceptable.

## Privacy

- Residents are worried about visitor names. The board agreed that the system should avoid storing real names.
- No personal data may be committed to the code repository.
- For the first version, all data in the system is fake or demo data.

## Language and accessibility

- The first version is in English. Other languages may come later.
- Some guards have poor eyesight. Text must be large and clear.
