# Constraints

## Budget

- Small. A one-time amount for building the first version and a very small yearly amount for hosting.
- No monthly fee for software licenses.

## Infrastructure

- No server for the pilot. IT does not want to run, secure or pay for one.
- The app must be able to be hosted as plain static files.

## Devices

- The administrator uses a laptop with a modern browser.
- Guards use company phones: recent iPhones and mid-range Android phones.
- Nobody wants to install an app from a store. A web page is acceptable.

## Privacy

- Visitor names are personal data. The first version must not store real names.
- No personal data may be committed to the code repository.
- For the first version, all data in the system is fake or demo data.

## Users

- There are only two kinds of user: the administrator, who creates passes, and the guard, who checks them.
- There is no sign-in. The first version has no accounts.

## Language and accessibility

- The first version is in English. Other languages may come later.
- Some guards have poor eyesight. Text must be large and clear.
